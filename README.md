# Sunflower Inc. Linux Course Design

A General Assembly hiring task: a Detailed Design and sample micro lesson for a 12-hour, instructor-led Linux course for 25 Sunflower employees new to technical work.

## What's here

- **Detailed Design**: units, learning objectives, sequence, tools, and assessments (coming soon)
- **Micro lesson**: one objective taught in slides with instructor notes (coming soon)

## Design approach

The course keeps the business outcomes from the High Level Design and sets success at a level that fits beginners. Advanced tasks, like mounting remote file systems, run as guided labs in a prepared environment.
