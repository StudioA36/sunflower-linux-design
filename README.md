# Sunflower Inc. Linux Course Design

A General Assembly hiring task: a Detailed Design and sample micro lesson for a 12-hour, instructor-led Linux course for 25 Sunflower employees new to technical work.

## What's here

- [Detailed Design](detailed-design.md): units, learning objectives, sequence, tools, and assessments for the 12-hour course
- [Micro lesson](micro-lesson.md): Unit 2, Objective 1, with a run of show, instructor notes, common errors, and sandbox setup
- **Review history:** see the closed pull requests for how the micro lesson was tested, reviewed, and revised

## How this project would run

| Step | Where it lives |
| --- | --- |
| 1. Receive the High Level Design | Provided by GA |
| 2. Refine the request with the client | Discovery interview; open questions listed in the Detailed Design |
| 3. Document and scope | [Detailed Design](detailed-design.md) |
| 4. Lead the team to build | [Micro lesson](micro-lesson.md) as a sample build, reviewed through pull requests |
| 5. Validate with the client | Validation plan in the Detailed Design |
| 6. Support implementation | Delivery team needs and sandbox setup |

## Design approach

The course keeps the business outcomes from the High Level Design and sets success at a level that fits beginners. Advanced tasks, like mounting remote file systems, run as guided labs in a prepared environment.

## Format

The micro lesson is delivered in markdown so it can be reviewed and revised through pull requests. It's written to be taught directly or built into slides by a designer. Visual design samples: [portfolio](https://www.studioa36.com)
